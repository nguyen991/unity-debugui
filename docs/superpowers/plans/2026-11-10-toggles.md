# Toggles Builder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `IDebugBuilder.Toggles(...)` — a wrapping row of toggle buttons bound to an enum (`[Flags]` = multi-select) or to a `string[]` with an `int` index / per-index `bool`.

**Architecture:** Every overload builds one UI Toolkit `ToggleButtonGroup` (a `BaseField<ToggleButtonGroupState>`) and goes through the existing `DebugBuilder.AddField<T>` with `T = ToggleButtonGroupState`, so polling, change-only UI updates, errors and read-only handling are reused. The conversions between game values and `ToggleButtonGroupState` live in a pure static class `ToggleStates`, tested on their own.

**Tech Stack:** Unity 6000.0+ (tested on 6000.6), UI Toolkit, NUnit PlayMode tests (`DebugUI.Tests` assembly).

**Spec:** `docs/superpowers/specs/2026-11-10-toggles-design.md`

## Global Constraints

- Package path: `Packages/com.ng.debugui`; namespace `Ng.DebugTools`; tests namespace `Ng.DebugTools.Tests`.
- Minimum Unity 6000.0: from `ToggleButtonGroupState` use only the `(ulong options, int length)` constructor, the `this[int]` indexer and `length`. Do **not** use `CreateFromOptions`, `FromEnumFlags`, `ToEnumFlags`, `GetActiveOptions` or `ToggleButtonGroup.GetButton` (may be missing on 6000.0). Find buttons with `group.Query<Button>()`.
- Max 64 buttons. More, or `options == null`, throws from the builder call (`ArgumentException` / `ArgumentNullException`).
- New USS class: `ngdbg-toggles` (constant `UssClasses.Toggles`).
- Defaults: `allowNone` = `false` for the `int` single-select overload, `true` for the multi `(int, bool)` overload and the enum overload (ignored for non-`[Flags]` enums, which are never empty). `buttonWidth` = `0` (fit text).
- Every public member gets an XML doc comment, like the rest of `IDebugBuilder`.
- Run tests in the open Editor (PlayMode must be async):
  ```bash
  unity command "test run" --mode playmode --async-tests --filter <TestClassName> --no-banner --result-only
  # then poll Temp/pipeline_test_status.json until "status": "completed"; read "summary" and failed results
  ```
  If the Editor is not reachable, use *Window → General → Test Runner → PlayMode*.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Game value changes while the panel is open** (e.g. cheats toggled from code) — the buttons must follow on the next refresh. Tested in Task 2 (`Toggles_Index_FollowsGameValue`) and Task 3 (`Toggles_Flags_FollowsGameValue`).
2. **`[Flags]` value with bits that have no button** (`All`, or a bit set by code) — writing back must keep those bits. Tested in Task 1 (`ToEnum_Flags_KeepsBitsWithoutButton`).
3. **Signed / negative enum values** (`enum E : sbyte { Low = -1, High = 1 }`) — must not throw. Tested in Task 1 (`EnumOptions_NegativeValues_Work`).
4. **Single-select with an out-of-range or `-1` game value and `allowNone: false`** — shows nothing selected, does not call the setter, does not throw. Tested in Task 2 (`Toggles_Index_OutOfRange_ShowsNothing_NoSetterCall`).
5. **Many options on a phone-width screen at `Scale = 2`** — buttons wrap instead of overflowing. Tested in Task 2 (`Toggles_ButtonsWrap`).

### Task 1: `ToggleStates` — conversions between game values and `ToggleButtonGroupState`

**Files:**
- Create: `Packages/com.ng.debugui/Runtime/ToggleStates.cs`
- Test: `Packages/com.ng.debugui/Tests/Runtime/ToggleStatesTests.cs`

**Interfaces:**
- Produces (all `internal static` in `internal static class ToggleStates`):
  - `ToggleButtonGroupState FromIndex(int index, int count)` — bit `index` set when `0 <= index < count`, else empty.
  - `int ToIndex(ToggleButtonGroupState state)` — first active index, or `-1`.
  - `ToggleButtonGroupState FromBools(Func<int, bool> isOn, int count)`.
  - `sealed class EnumOptions<TEnum> where TEnum : struct, Enum` with `string[] Names`, `bool IsFlags`, `ToggleButtonGroupState ToState(TEnum value)`, `TEnum ToEnum(ToggleButtonGroupState state, TEnum current)`; built with `static EnumOptions<TEnum> Get()` (cached per type).

- [ ] **Step 3: Implement `ToggleStates`.**
  - Convert enum values with `Convert.ToInt64(value)` then `unchecked((ulong)…)` so signed enums work; never `Convert.ToUInt64`.

  - `ToEnum` for flags: `(current & ~buttonMask) | selectedBits`; convert back with `(TEnum)Enum.ToObject(typeof(TEnum), …)`.
  - More than `MaxOptions` buttons → `ArgumentException` naming the enum type.
